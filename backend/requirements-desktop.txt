# LEAN PRODUCTION REQUIREMENTS — hosted desktop-companion backend (BYOK)
#
# This is the deploy profile for the Oracle-hosted backend that serves the
# Windows desktop app. It is intentionally MINIMAL: only the deps on the live
# runtime path (FastAPI WS + Deepgram STT + Gemini/OpenAI/Anthropic BYOK +
# vision) are included.
#
# The full local-dev / research stack stays in `requirements.txt` (unchanged).
# DO NOT install both into the same env.
#
# Verified against the real startup import chain (2026-05-30):
#   app.main -> websocket -> negotiation_engine -> companion_runtime /
#   listener_agent / stt_service. The only non-core module-top imports on that
#   chain are `numpy` (listener_agent) and `huggingface_hub` (main.py shim).
#   All torch / speechbrain / pyannote / whisper / wespeaker / webrtcvad /
#   scipy imports are LAZY (inside functions) and only fire if speaker-ID /
#   diarization is enabled — which is OFF in production (see prod .env).
#
# Required prod env (so no heavy/lazy path or Vertex auth is ever invoked):
#   SPEAKER_RECOGNITION_ENABLED=False
#   SPEECHBRAIN_ENABLED=False
#   PERFECT_LISTENER_ENABLED=False
#   TRANSCRIPTION_PROVIDER=deepgram
#   GOOGLE_GENAI_USE_VERTEXAI=False        (BYOK = Google AI Studio, no GCP)
# ─────────────────────────────────────────────────────────────────────────────
