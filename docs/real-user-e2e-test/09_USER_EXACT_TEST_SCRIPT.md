# User Exact Test Script

Use this file for **your exact lines**.

This script is one coherent procurement renewal call. The numbers are fixed and the logic is consistent from start to finish.

## Deal Setup

- Product: B2B customer support SaaS
- Scope: **120 seats**
- Last contract: **$84,000 annual**
- Vendor renewal quote: **$96,000 annual**
- Your opening target: **$76,000 annual**
- Your realistic target: **$80,000 annual**
- Your approval cap: **$82,000 annual**
- You only accept **$82,000** if it includes all of these:
  - 12-month price lock
  - onboarding included
  - 99.9% uptime SLA with service credits
  - net-60 payment terms
  - no automatic renewal
